## 1. Підготовка сервера

Перед встановленням будь-якого ПЗ оновіть систему:

```bash
sudo apt update && sudo apt upgrade -y
```

> 💡 Якщо з'явиться фіолетове вікно з пропозицією перезапустити сервіси — просто натисніть **Enter**.

---

## 2. Встановлення Apache

Apache — вебсервер, який відповідає за відображення сторінок.

```bash
sudo apt install apache2 -y
```

Перевірте статус (для виходу натисніть **Q**):

```bash
sudo systemctl status apache2
```

---

## 3. Встановлення MySQL

```bash
sudo apt install mysql-server -y
```

Запустіть скрипт безпеки:

```bash
sudo mysql_secure_installation
```

| Запитання | Відповідь |
|---|---|
| `VALIDATE PASSWORD COMPONENT` | **N** |
| Пароль для `root` | Придумайте та **запишіть** надійний пароль |
| Всі наступні запитання | **Y** |

---

## 4. Встановлення PHP

Zippy CRM потребує PHP 8.3 та кілька розширень для роботи з графікою, архівами і текстом:

```bash
sudo apt install php libapache2-mod-php php-mysql php-cli php-curl \
  php-json php-gd php-mbstring php-xml php-zip unzip git -y
```

## 5. Встановлення phpMyAdmin

```bash
sudo apt install phpmyadmin -y
```

**Під час інсталяції:**

- Виберіть вебсервер `apache2` стрілочками, натисніть **Пробіл** (має з'явитися `[*]`), потім **Tab** → **Enter**
- На запитання про `dbconfig-common` — **Yes**
- Введіть і підтвердьте пароль для phpMyAdmin

### Створення адміна для phpMyAdmin

Сучасна MySQL не дозволяє входити під `root` через браузер. Створіть окремого користувача:

```bash
sudo mysql
```

```sql
CREATE USER 'admin_user'@'localhost' IDENTIFIED BY 'Ваш_Пароль';
GRANT ALL PRIVILEGES ON *.* TO 'admin_user'@'localhost' WITH GRANT OPTION;
FLUSH PRIVILEGES;
EXIT;
```

Після цього phpMyAdmin буде доступний за адресою: `http://<IP_сервера>/phpmyadmin`

## 6. Розгортання файлів Zippy CRM

Очистіть стандартну вебпапку якщо вона у вас була:

```bash
cd /var/www/html
sudo rm -rf *
```

Клонуйте репозиторій і скопіюйте вміст папки `www`:

```bash
cd ~
git clone https://github.com/leon-mbs/zstore.git
sudo mkdir -p /var/www/html/
sudo cp -r ~/zstore/www/* /var/www/html/
```
Перевіряємо, чи з'явилися файли всередині папки:

```bash
ls -la /var/www/html/
```
У відповідь термінал має вивести список файлів  ZStore (там будуть папки config, index.php тощо).

---

## 7. Створення та імпорт бази даних

1. Відкрийте phpMyAdmin під `admin_user`
2. Перейдіть: **Облікові записи користувачів** → **Додати обліковий запис**
3. Заповніть:
   - **Username:** `zstore_user`
   - **Hostname:** `localhost`
   - **Password:** придумайте і запишіть
4. Поставте галочку: **"Створити базу даних з таким самим іменем і надати всі привілеї"**
5. Натисніть **Go**

Імпортуйте структуру БД:

```bash
mysql -u zstore_user -p zstore_user < ~/zstore/db/db.sql
```

Після успішного імпорту видаліть тимчасову папку:

```bash
rm -rf ~/zstore
```

## 8. Конфігурація сайту та права доступу

Налаштуйте права для Apache:

```bash
sudo chown -R www-data:www-data /var/www/html/
sudo find /var/www/html/ -type d -exec chmod 755 {} \;
sudo find /var/www/html/ -type f -exec chmod 644 {} \;
```
Обов'язково надайте підвищені права на запис для папок логів та завантажень, як того вимагає розробник:
```bash
sudo chmod -R 775 /var/www/html/logs
sudo chmod -R 775 /var/www/html/upload
```

Перейдіть у папку з конфігураційними файлами CRM:

```bash
cd /var/www/html/config
```
Відкрийте файл config.php для редагування :

```bash
sudo nano config.php
```

Відредагуйте параметри підключення:

```php
$db_host = "localhost";
$db_user = "zstore_user";
$db_pass = "Ваш_Пароль_Користувача_БД";
$db_name = "zstore_user";
```

Збережіть: **Ctrl+O** → **Enter** → **Ctrl+X**

## 9. Налаштування ЧПУ в Apache

Активуйте модуль `rewrite`:

```bash
sudo a2enmod rewrite
```

Відкрийте конфіг сайту:

```bash
sudo nano /etc/apache2/sites-available/000-default.conf
```

Додайте всередині блоку `<VirtualHost *:80>` перед закриваючим тегом:

```apache
<Directory /var/www/html>
    Options Indexes FollowSymLinks
    AllowOverride All
    Require all granted
</Directory>
```

Перезапустіть Apache:

```bash
sudo systemctl restart apache2
```

## 10. Підключення власного домену

> Якщо хочете відкривати сайт за доменним іменем (наприклад, у безкоштовній зоні `.pp.ua`) замість IP-адреси.

### Що знадобиться

- **Публічна IP-адреса** сервера (дізнатися командою: `curl ifconfig.me`)
- **Доступ до панелі реєстратора** домену (Nic.ua, Imena.ua, Regery тощо). Мені подобається https://98.com.ua/

> ⚠️ Потрібна саме «біла» (публічна) IP-адреса. Якщо провайдер видає «сіру» (NAT) — домен ззовні працювати не буде. Замовте послугу «Статична IP» у провайдера.

### Крок 1. NS-сервери реєстратора

Зайдіть у кабінет реєстратора, знайдіть свій домен і переконайтеся, що в розділі **NS-сервери** вибрано власні сервери реєстратора (наприклад, для NIC.ua: `ns1.nic.ua`, `ns2.nic.ua`). 

### Крок 2. Налаштування A-записів

Перейдіть у розділ **«Керування DNS»** для вашого домену та додайте два записи:

| Тип | Хост | Значення | Результат |
|---|---|---|---|
| **A** | `@` | `Ваша_IP_адреса` | `vash-domen.pp.ua` → сервер |
| **A** | `www` | `Ваша_IP_адреса` | `www.vash-domen.pp.ua` → сервер |

> 💡 Для додаткового піддомену (наприклад, `crm.vash-domen.pp.ua`) — додайте ще один A-запис з хостом `crm` і тією самою IP-адресою.

### Крок 3. Очікування оновлення DNS

DNS-сервери оновлюються не миттєво. Зазвичай від **15 хвилин до кількох годин** (іноді до 24 годин для зони `.pp.ua`). Поки оновлення не завершилося — сайт за доменом може не відкриватись, це нормально.

Перевірити готовність можна командою:

```bash
ping vash-domen.pp.ua
```

Якщо пакети йдуть на вашу IP-адресу — домен прив'язався успішно.

### Можливі проблеми

**Сайт не відкривається, хоча ping проходить** — провайдер блокує порти `80` (HTTP) і `443` (HTTPS). Перевірте налаштування **Port Forwarding** на роутері: порти 80 і 443 мають перенаправлятися на внутрішню IP-адресу вашого Ubuntu Server.

## 11. Встановлення SSL-сертифіката (HTTPS)

> ⚠️ **Умова:** Сертифікат видається лише на реальне доменне ім'я. Переконайтеся, що домен вже прив'язаний до IP сервера (крок 10) і успішно пінгується.

Використовуємо **Certbot** — утиліту, яка автоматично отримає безкоштовний сертифікат від Let's Encrypt та налаштує Apache.

### Крок 1. Встановлення Certbot

```bash
sudo snap install core; sudo snap refresh core
sudo snap install --classic certbot
sudo ln -s /snap/bin/certbot /usr/bin/certbot
```

### Крок 2. Отримання сертифіката

```bash
sudo certbot --apache
```

Certbot запустить інтерактивне налаштування:

| Запитання | Відповідь |
|---|---|
| Email | Введіть свою адресу (сюди прийдуть сповіщення про закінчення терміну) |
| Умови використання Let's Encrypt | **Y** |
| Розсилка від EFF | **N** |
| Вибір домену | Введіть цифру зі списку або вручну: `vash-domen.pp.ua www.vash-domen.pp.ua` |

Після успішного завершення побачите: `Congratulations! You have successfully enabled HTTPS on...`

Certbot автоматично перепише конфіги Apache та налаштує редирект з `http://` → `https://`.

### Крок 3. Перевірка автооновлення

Сертифікат дійсний **90 днів**, але Certbot сам його оновлює у фоні. Перевірте, що механізм працює:

```bash
sudo certbot renew --dry-run
```

Якщо побачите `Congratulations, all simulated renews succeeded` — все гаразд, більше нічого робити не потрібно.

## 12. Альтернатива: Встановлення через вебпанель FASTPANEL

> ⚠️ **УВАГА:** Цей крок є повною альтернативою Крокам 2–5 та 9–11. Вебпанель автоматично встановлює та налаштовує весь необхідний софт (Apache/Nginx, PHP, MySQL, phpMyAdmin, SSL). **Встановлювати FASTPANEL можна ТІЛЬКИ на абсолютно чисту ОС Ubuntu Server!** Якщо ви вже виконали попередні кроки консоллю, цей крок робити не можна — система зламається через конфлікт портів.

Якщо ви не хочете постійно працювати в консолі і віддаєте перевагу керуванню сайтами, базами даних та файлами через зручний інтерфейс у браузері, можна розгорнути сервер за допомогою безкоштовної панелі **FASTPANEL**  https://fastpanel.direct/.

### Покрокове встановлення на чистий сервер:

1. Підключіться до вашого чистого сервера через SSH під користувачем `root`. Якщо ви увійшли під своїм користувачем (наприклад, `user`), спочатку перейдіть у режим суперкористувача:
   ```bash
   sudo su
   ```
2. Запустіть офіційний скрипт автоматичного встановлення панелі:
```
wget -O - [https://repo.fastpanel.direct/install_fastpanel.sh](https://repo.fastpanel.direct/install_fastpanel.sh) | bash -
```
3. Дочекайтеся завершення процесу (це займе кілька хвилин). По завершенню термінал виведе повідомлення з даними для входу:
```
Congratulations! FASTPANEL® successfully installed and available now for you:
URL: https://<IP_вашого_сервера>:8888/
Login: cpuser
Password: <випадковий_пароль>
```
 Перше налаштування у браузері:
1. Перейдіть за посиланням https://<IP_вашого_сервера>:8888/ (Браузер може попередити про небезпечне з'єднання, оскільки сертифікат панелі ще самопідписаний — натисніть Додатково ➡️ Перейти).

2. Панель попросить ввести email для отримання безкоштовної ліцензії (ліцензія активується автоматично в один клік).

3. Увійдіть, використовуючи логін cpuser та пароль, який видала консоль. Потім панель запропонує змінити цей пароль на ваш власний.

Розгортання ZStore всередині панелі:
Замість Кроків 6–8, усе робиться через інтерфейс:

* **Створення сайту:** Натисніть кнопку **"Створити сайт"** ➡️ оберіть ваш домен ➡️ панель сама налаштує віртуальний хост.
* **База даних:** У картці сайту перейдіть у розділ **"Бази даних"** ➡️ натисніть **"Створити"** (база та користувач створяться миттєво). Там же буде посилання на вбудований phpMyAdmin, де можна зробити імпорт файлу `db.sql`.
* **Завантаження файлів:** У розділі **"Файловий менеджер"** ви зможете завантажити вміст папки `www` проєкту ZStore прямо через браузер без використання команд `cp` чи `chown` (панель сама виставить потрібні права користувача).
* **SSL-сертифікат:** У розділі **"Сертифікати SSL"** натисніть **"Новий сертифікат"** ➡️ оберіть *Let's Encrypt* ➡️ панель сама випустить сертифікат та налаштує HTTPS-редирект.
